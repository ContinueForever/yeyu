`manifest.json` 固定矩阵、版本分组和地址映射说明；各数据集的 `cases/` 保留全部客户端样本及前后状态，`trace/` 为完整数值追踪的 gzip；`scheduler/scheduler/` 保留完整解码的调度事件。`local/` 冻结源码与历史测试日志按原始字节保留；其他诊断文本中的实验节点地址／主机名和私有目录前缀已经映射为示例值。PID、TID、端口和同机单调时间戳保留，用于关联。

原始二进制 perf.data、包捕获、业务备份、运行程序和密钥不在此归档中。抓包结论保留为摘要，其独立包级重算仍需私有捕获；此工具不声称已经重新核验包级归因。源码归档保留历史测试常量，不修改已经测试过的代码字节。文件哈希保证材料内部一致性，不独立认证远端机器。

数值追踪有按 1/32 采样及服务端慢读保留偏差。各轮分位数以完整客户端样本为准，多个阶段的 P99 不能相加。原程序 CPU 0 组三轮吞吐中位数约 +32%、P99 43.225→7.617 ms，同时仍有 87.525 ms 单次尾部。

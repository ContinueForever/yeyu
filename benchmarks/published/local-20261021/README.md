从仓库根目录运行：

```bash
python3 scripts/verify-evidence.py benchmarks/published/local-20261021
```

该命令校验公开文件 SHA-256、历史源码归档与清单、27 轮性能计数／百分位／逐秒分桶，并重新对 948 轮故障历史执行有界逐 key 模型检查。它不启动服务器，不重新测量硬件性能。实验复现命令见[性能工具说明](../../README.md)。

记录按白名单从原始输出复制，测量值未改写。故障历史和逐轮结果无损合并为 gzip JSON Lines。原始机器路径、运行命令、二进制与源码哈希保留用于追溯，不要求检出路径与原机器相同。

节点数据目录、锁文件、业务数据、后台服务备份及编译产物不在公开集合中。所附源码归档均已检查成员清单，仅包含当时的项目代码／文档；早期 RPC 实验中混入其他文档的归档仍未公开。

`publication-manifest.json` 列出本集合每个文件的大小与 SHA-256。发布清单只校验记录完整性，不能单独证明实验结论。历史源码比当前提交更早；重新运行可能因硬件、调度和持久化介质不同而得到不同结果。

# 文档导航

当前实现为固定三个 voter、单 Raft Group 的 C++17 KV 服务，默认使用增量 journal、ReadIndex、自适应快照、同步 KV 编码与同步磁盘执行，支持两个独立的后台开关和 revision／CAS。交付基线 CI 普通／ASan＋UBSan 各 189 项通过；队列与后台执行组件 TSan 31 项通过。18 轮同期对照与可选后台磁盘六小时稳定性实验已收尾，整体性能门槛仍失败、默认同步。当前作为求职项目交付，历史实验的版本与解释范围分列如下。

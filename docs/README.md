# 文档导航

当前实现为固定三个 voter、单 Raft Group 的 C++17 KV 服务，默认使用增量 journal、ReadIndex、自适应快照与同步编码，支持可选后台编码和 revision／CAS。短任务普通／ASan 各 148 项已通过，最新完成三机六小时窗口与六次整组重启验收，见下方对应报告。

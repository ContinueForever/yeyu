# 文档导航

当前实现为固定三个 voter、单 Raft Group 的 C++17 KV 服务，默认使用增量 journal、ReadIndex 和自适应快照。已有同机三进程回归与性能证据，并完成三台 ECS 的基础正确性手工演练；后者原始日志仍待归档，见下方对应记录。
